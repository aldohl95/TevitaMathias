# Tevita Mathias: Portfolio

My professional technology portfolio: who I am, four featured projects with links to their source code, my skills, and my resume.

**Live site:** https://aldohl95.github.io/TevitaMathias/

## What's in this repo

| Path | Purpose |
|---|---|
| `index.html` | The whole site: About me, Featured projects, Skills and tools, Resume and links, Contact |
| `styles.css` | Styles, including dark mode and a layout for phones and tablets |
| `assets/Tevita-Mathias-Resume.pdf` | Resume, shared without my phone number |

## How it's built

Plain HTML and CSS, with no framework, build step, or JavaScript. It is hosted with GitHub Pages from the `main` branch.

- Semantic headings and landmarks, a skip link, visible keyboard focus, and text contrast that meets WCAG AA.
- Responsive from small phones to wide desktops.
- Every project links to real source code, tests, or design documents so claims can be checked.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Update it

1. Edit `index.html` or `styles.css`.
2. To replace the resume, save the new PDF over `assets/Tevita-Mathias-Resume.pdf`.
3. Commit and push to `main`. GitHub Pages republishes within a minute or two.
